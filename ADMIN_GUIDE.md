## Первичная настройка

### Шаг 1: Создание аккаунта на GitHub

1. Перейдите на сайт [github.com](https://github.com)
2. Нажмите **"Sign up"** (Зарегистрироваться) в правом верхнем углу
3. Заполните форму регистрации:
   - Введите ваш email
   - Придумайте пароль
   - Придумайте имя пользователя (username)
   - Пройдите проверку (puzzle)
4. Подтвердите email (проверьте почту и нажмите на ссылку)
5. Завершите регистрацию

### Шаг 2: Отправка username администратору

После создания аккаунта:
1. Скопируйте ваше имя пользователя (username)
2. Отправьте его администратору проекта (Т.е. мне Кудайбергену)
3. Дождитесь приглашения в проект

**Пример:** Если ваш username: `ivan_psychologist`, отправьте именно это имя.

### Шаг 3: Принятие приглашения

1. Проверьте вашу почту - придет письмо с приглашением от GitHub
2. Откройте письмо и нажмите **"View invitation"**
3. На странице приглашения нажмите **"Accept invitation"** (Принять приглашение)
4. Теперь у вас есть доступ к проекту!

## Как редактировать список психологов

### Шаг 1: Открытие проекта

1. Войдите в свой аккаунт на [github.com](https://github.com)
2. Перейдите в репозиторий проекта: https://github.com/Katalip/empathy-landing
3. Вы увидите список файлов проекта

### Шаг 2: Поиск файла с психологами

1. В списке файлов найдите папку **`src`**
2. Откройте папку **`src`**
3. Найдите и откройте папку **`data`**
4. Найдите файл **`psychologists.json`**
5. Нажмите на файл, чтобы открыть его

### Шаг 3: Редактирование файла

1. В открытом файле нажмите на значок карандаша **✏️** (Edit this file) в правом верхнем углу
2. Теперь вы можете редактировать содержимое файла
3. Будьте внимательны с форматированием! (см. раздел "Структура данных")

### Шаг 4: Сохранение изменений (Create Pull Request)

После внесения изменений:

1. Прокрутите страницу вниз до раздела **"Propose changes"** (Предложить изменения)
2. В поле **"Commit message"** опишите, что вы изменили. Например:
   - `Добавлен новый психолог: Мария Иванова`
   - `Обновлены контактные данные Арнура`
   - `Изменена стоимость сессий`
3. Нажмите зеленую кнопку **"Propose changes"** (Предложить изменения)
4. На следующей странице нажмите **"Create pull request"** (Создать запрос на изменение)
5. Еще раз проверьте описание и нажмите **"Create pull request"**

### Шаг 5: Ожидание проверки

1. Ваши изменения отправлены на проверку администратору
2. Администратор проверит и одобрит изменения
3. После одобрения изменения автоматически появятся на сайте (через ~2 минуты)
4. Вы получите уведомление на email

## Структура данных психолога

Каждый психолог представлен блоком данных в формате JSON. Вот полная структура:

```json
{
  "name": "Имя Фамилия",
  "role": "Должность",
  "specialization": "Краткая специализация",
  "experience": "X лет опыта",
  "image": "/photo.jpg",
  "verified": true,
  "education": "Полное описание образования",
  "approach": "Метод терапии",
  "languages": ["Русский", "Казахский"],
  "sessionPrice": "12,000 ₸",
  "type": "therapist",
  "shortRequests": "Краткое описание запросов",
  "fullRequests": [
    "Полный список запросов",
    "По одному запросу в строке"
  ],
  "disorders": [
    "Расстройство 1",
    "Расстройство 2"
  ],
  "formats": ["онлайн", "оффлайн в Астане"],
  "fullDescription": "Полное описание специалиста"
}
```

### Описание полей:

| Поле | Описание | Пример |
|------|----------|--------|
| `name` | Имя и фамилия | "Арнур Кожагапаров" |
| `role` | Должность | "Кризисный психолог" |
| `specialization` | Краткая специализация | "Работа с детьми и подростками" |
| `experience` | Опыт работы | "5 лет опыта" |
| `image` | Путь к фото | "/arnur.jpg" |
| `verified` | Верифицирован (true/false) | true |
| `education` | Образование (полное) | "КазНУ, магистр психологии..." |
| `approach` | Метод терапии | "Когнитивно-поведенческая терапия" |
| `languages` | Список языков | ["Русский", "Казахский"] |
| `sessionPrice` | Стоимость сессии | "12,000 ₸" |
| `type` | Тип (therapist/consultant) | "therapist" |
| `shortRequests` | Краткое описание запросов | "Работает с тревожностью..." |
| `fullRequests` | Полный список запросов | Массив строк |
| `disorders` | Расстройства | Массив строк |
| `formats` | Форматы работы | ["онлайн", "оффлайн в Астане"] |
| `fullDescription` | Полное описание | Подробный текст о специалисте |

## Примеры редактирования

### Пример 1: Добавление нового психолога

Найдите последнего психолога в списке (ищите закрывающую фигурную скобку `}`) и после нее добавьте запятую и новый блок:

```json
  },
  {
    "name": "Новый Психолог",
    "role": "Психолог-консультант",
    "specialization": "Работа со стрессом",
    "experience": "3 года опыта",
    "image": "/new_psychologist.jpg",
    "verified": false,
    "education": "КазНПУ, бакалавр психологии",
    "approach": "Когнитивно-поведенческая терапия",
    "languages": ["Русский"],
    "sessionPrice": "12,000 ₸",
    "type": "therapist",
    "shortRequests": "Помогает справиться со стрессом",
    "fullRequests": [
      "Стресс и тревожность",
      "Эмоциональное выгорание"
    ],
    "disorders": [],
    "formats": ["онлайн"],
    "fullDescription": "Описание нового психолога..."
  }
```

**⚠️ ВАЖНО:** Не забудьте запятую после предыдущего психолога!

### Пример 2: Изменение телефона и email

Найдите нужного психолога и измените нужные поля:

```json
{
  "name": "Арнур Кожагапаров",
  "experience": "6 лет опыта"  ← Изменили с "5 лет" на "6 лет"
}
```

### Пример 3: Добавление новых запросов

Добавьте новые строки в массив `fullRequests`:

```json
"fullRequests": [
  "Горевание и утрата",
  "Буллинг и моббинг",
  "Новый запрос 1",  ← Добавили
  "Новый запрос 2"   ← Добавили
]
```

### Пример 4: Добавление расстройств

Добавьте расстройства в массив `disorders`:

```json
"disorders": [
  "Тревожные расстройства",
  "Депрессивные расстройства"
]
```

### Пример 5: Удаление психолога

Найдите блок психолога (от `{` до `}`), включая запятую после него, и удалите полностью:

```json
  },  ← Конец предыдущего психолога
  {
    "name": "Удаляемый Психолог",
    ...весь блок...
  },  ← Удалите всё от { до },
  {   ← Следующий психолог
```

## Часто задаваемые вопросы

### ❓ Что делать, если я ошибся при редактировании?

Не волнуйтесь! Изменения не применятся сразу. Администратор проверит ваш Pull Request и может:
- Исправить ошибки
- Попросить вас внести правки
- Отклонить изменения (если что-то не так)

### ❓ Как быстро изменения появятся на сайте?

После того как администратор одобрит ваш Pull Request, изменения автоматически появятся на сайте через ~2 минуты.

### ❓ Можно ли редактировать несколько психологов одновременно?

Да! Можете внести все нужные изменения в одном редактировании, а затем создать один Pull Request.

### ❓ Что означает ошибка "Invalid JSON"?

Это значит, что в файле нарушен формат JSON. Частые причины:
- Забыли запятую между элементами
- Лишняя запятая после последнего элемента
- Не закрыли кавычки или скобки
- Используете одинарные кавычки вместо двойных

**Совет:** Используйте [jsonlint.com](https://jsonlint.com/) для проверки правильности JSON.

### ❓ Где взять фото психолога?

Фото должны быть загружены администратором в папку `/public/`. Имя файла указывается в поле `"image"`.

### ❓ Как изменить порядок психологов?

Психологи отображаются в том порядке, в котором они указаны в файле. Чтобы изменить порядок, скопируйте и переместите целые блоки `{ ... }`.

### ❓ Нужно ли обновлять поле "lastmod" в sitemap.xml?

Нет, не нужно. Это делается автоматически при деплое.

## Важные правила

### ✅ DO (Делайте так):
- Используйте двойные кавычки `"` вместо одинарных `'`
- Ставьте запятую после каждого элемента, кроме последнего
- Проверяйте формат перед сохранением
- Пишите понятные описания изменений

### ❌ DON'T (Не делайте так):
- Не удаляйте квадратные `[]` или фигурные `{}` скобки
- Не забывайте закрывать кавычки
- Не ставьте запятую после последнего элемента в массиве
- Не используйте специальные символы без экранирования
